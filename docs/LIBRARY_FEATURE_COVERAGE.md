# Library Feature Coverage

This map records where the former Organize and Edit capabilities appear in Library. Capture is unchanged. Create and Send remain separate modules.

| Existing capability | Previous location | Library location | Treatment |
| --- | --- | --- | --- |
| Browse saved PhotoNotes | Organize and Edit | Saved PhotoNotes grid | Consolidated |
| Search and filters | Organize | Search | Preserved |
| Saved searches | Organize | Search | Preserved |
| Select photos | Organize and Edit | Photo checkbox, Select All, Clear Selection | Consolidated |
| Project assignment and project creation | Organize | Projects and Selected PhotoNotes | Preserved |
| Topics and batch metadata | Organize | Selected PhotoNotes | Preserved |
| Documents and export presets | Organize | Selected PhotoNotes and Library tools | Preserved |
| Before and after comparison | Organize | Selected PhotoNotes | Preserved |
| Photo title and note editing | Edit and card actions | Open PhotoNote | Consolidated |
| Crop, rotate, markup, restore, measurements, and classification | Edit | Open PhotoNote | Preserved |
| Capture details and history | Organize and Edit | Open PhotoNote | Preserved |
| Comments, favorites, flags, and related photos | Organize and Edit | Open PhotoNote, with favorites and flags also available as filters | Preserved |
| Delete PhotoNote | Organize | Open PhotoNote | Preserved |
| Scheduled photography | Photo Follow-Ups below Organize | Scheduled Photos at the top of Library | Renamed and clarified |
| Specialty evidence and industry actions | Organize and Edit | Open PhotoNote and specialist workspaces | Preserved |
| Duplicate for New Photo, Take Matching Photo, and QR card action | Saved-card actions | Existing underlying records remain; removed from the general Library PhotoNote action surface | Intentionally removed from this surface by owner decision |
| Property Manager and HOA visits, assets, inspections, and maintenance records | Specialist tabs | Existing specialist tabs | Preserved |

The production data model currently assigns one project or job to a PhotoNote. The Library labels are prepared for Project(s) and Group(s), but multi-project membership requires a separate data-model change and migration before it can be represented truthfully.
