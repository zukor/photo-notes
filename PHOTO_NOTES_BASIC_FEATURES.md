# Photo Notes Basic — Features by Section

## Product Purpose

Photo Notes Basic is a general-purpose photo documentation application. It combines photographs, dictated or typed notes, dates, locations, addresses, topics, and supporting evidence into organized records that can be edited, documented, downloaded, and shared.

This document covers the **Basic version only**. It does not include Asphalt Pro, HOA Maintenance Pro, AI measurement, asphalt classification, industry scanners, extra-work records, or other Pro-only tools.

## Capture

### Take or Import a Photo

- Take a new photo with the device camera.
- Choose an existing image from the photo library or device files.
- Preview the selected photo before saving.
- Save a typed note without a photo when needed.

### Voice and Written Notes

- Record a spoken note using the device microphone.
- Display the recognized words in the note field.
- Edit the dictated text before saving.
- Type or supplement a note manually.

### Location Documentation

- Record GPS coordinates when location access is available.
- Convert the coordinates into a complete street address.
- Save the location and address with the capture.

### Topics

- Assign a topic while capturing a photo.
- Create new topics directly from the Capture page.
- Remove topics that are no longer needed without removing the labels from previously saved photos.

### Projects and Jobs

- Assign a new capture to an active job.
- Leave a capture outside a job when job organization is unnecessary.

### Automatic Photo Quality Check

- Check a selected photo for common quality problems.
- Warn about issues such as low resolution, blur, darkness, overexposure, or poor framing.
- Allow the user to retake the photo or save it after reviewing the warning.

### Offline Field Capture

- Save captures on the device when the internet connection is unavailable.
- Show that a photo is waiting to upload.
- Automatically resume uploading when the connection returns.

### Saving

- Save the photo, note, topic, date, location, address, and job assignment as one capture.
- Upload the record in the background so the user can continue working.
- Preserve an evidence fingerprint for the original uploaded file.

## Organize

### Photo Library

- View saved photos and notes as cards.
- See the capture date and time, address or coordinates, topic, job, and note.
- Select individual photos or select all visible photos.
- Clear the current selection.

### Topics

- Filter the library by topic.
- Apply an existing topic to multiple selected photos.
- Create a new topic while organizing photos.

### Projects and Jobs

- Create jobs with a name, job number, customer, and address.
- Filter photos by job.
- Move multiple selected photos into a job.
- View a chronological photo timeline for a job.
- Mark a job complete or reopen it.

### Smart Photo Search

- Search notes, job names, customers, addresses, topics, dates, and other saved photo information.
- Limit results to a date range.
- Find captures that are missing an address.
- Combine search criteria with a topic or job filter.

### Photo Comparison

- Select two photos and compare them side by side.
- Use an overlay view and opacity control to inspect visual differences.

### Document Organization

- Add selected photos to an existing document.
- Create a new document from selected photos.
- Preserve the selected photos for use in the Create section.

### Batch Photo Processing

- Move multiple selected photos to a job.
- Apply a reusable annotation template to multiple photos.
- Available templates include Date and Address, Evidence Details, and Copyright Only.

## Edit

### Photo Selection and Filtering

- Filter photos by topic.
- Select individual photos or all visible photos.
- Clear the current selection.

### Photo Orientation

- Rotate a photo left or right by 90 degrees.
- Flip a photo horizontally.

### Crop and Restore

- Crop a photo using an adjustable crop area.
- Keep the original photograph when a crop is applied.
- Restore the original version later.

### Photo Markup and Annotation

- Add date and time, address, GPS coordinates, copyright text, topic, custom text, rectangles, and arrows to a photo.
- Move and resize annotations on the image.
- Change annotation color, font, size, and line thickness where applicable.
- Apply a Date and Address, Evidence Details, or Copyright Only template.
- Save the annotations with the Photo Notes record.
- Download a separate image with the markings permanently visible.

### Notes and Addresses

- Edit the written note attached to a capture.
- Correct an individual address manually.
- Run Fix Addresses on selected or available captures to retry complete-address lookup.

### Photo Evidence Verification

- Display the original file's SHA-256 fingerprint when available.
- Verify whether the stored original still matches its fingerprint.
- Show original file size, receipt time, GPS availability, address availability, and original-backup status.
- Display a history of later changes such as note edits, rotation, flipping, cropping, and restoration.
- Keep private note text out of the evidence-history descriptions.

### Deletion

- Delete selected captures after confirmation.

## Create

### Document Setup

- Create a document with a title and optional subtitle or description.
- Start with selected photos or create an empty document.
- Display existing documents as soon as the Create section opens.
- Open a newly created document immediately for editing.

### Document Contents

- Add organized photos to a document.
- Preview the photographs and captions in document order.
- Edit and save individual photo captions.
- Move photos up or down.
- Reverse the entire photo order.
- Remove a photo from the document without deleting the original capture.

### Document Details

- Edit the document title.
- Edit the subtitle or description.
- Delete a document without deleting its underlying photos.

### Finished Documents

- Generate a PDF document.
- Generate a Microsoft Word document.
- Generate a ZIP package designed for use with AI tools.
- Choose export resolution: web, standard, print quality, or full resolution.
- Choose JPEG, PNG, WebP, or the original image format where supported.
- Include photo captions, dates, topics, and locations in the finished document.

## Send

### Share Selected Photos

- Select captures directly from the Send page.
- Open the device's available share options for selected photos.
- Send selected captures as a PDF.
- Send selected captures as a Word document.
- Use complete addresses and notes as photo information when sharing.

### Customer Approval Package

- Create a private review link for selected photos.
- Add a review title and an optional message.
- Set the link to expire automatically after 14 days.
- Allow the recipient to approve the photos or request changes.
- Record the recipient's name and optional comment.
- Review the status of recent customer approval links.
- Copy an existing review link for reuse.

### Send or Save a Document

- Share a finished document as a PDF.
- Print a document.
- Save a PDF.
- Save a Word document.
- Download an AI ZIP package.

### Mac-to-Android Messaging Notice

- Explain that sending to an Android phone from a Mac requires the paired iPhone's Text Message Forwarding and MMS or RCS settings.

## Features Available Throughout the Basic App

### Account Controls

- Sign in with an email address and password.
- Open the profile menu to see the user's name, email address, and Basic plan.
- Sign out from the profile menu.

### English and Spanish

- Switch between English and Spanish from the application header.
- Retain the selected language for later visits.

### Report an Issue

- Open the Report an Issue control from any Basic-version page.
- Automatically capture an image of the current page when possible.
- Dictate or type a detailed problem description.
- Submit the page name, screenshot, and description for review.

### Responsive Access

- Use the same account and saved information on phones, tablets, and desktop web browsers.
- Open to Capture on handheld devices for faster field documentation.
- Open to Organize on desktop computers for faster review and organization.
